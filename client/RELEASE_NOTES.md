## Cavil Loop 客户端

本地看板客户端：把多个 GitHub Project 和仓库放进一个视图，按迭代 / 状态 / 里程碑分列，可按仓库分泳道；断网时显示上次同步的内容。点卡片看详情（评论最新在上），可以加 / 删标签、改迭代 / 状态 / 里程碑（下拉或拖卡）、新建 issue、回复评论并一键交回 agent、合并或关闭 PR；断网时这些都变灰。带 `pending/human` 的条目新出现时发系统通知，Dock 角标显示总数；关掉窗口后在后台继续同步。搜索筛选在后续版本。

### 下载哪个

- Apple 芯片（M1 及以后）：`Cavil-Loop-<版本>-arm64.dmg`
- Intel 芯片：`Cavil-Loop-<版本>-x64.dmg`

不确定的话：左上角苹果菜单 →「关于本机」，「芯片」一栏写 Apple M… 就选 arm64。

### 第一次打开（App 没有苹果签名，macOS 会拦一次）

打开 dmg 后的窗口里也写着下面的放行办法；命令可以从窗口里的「打不开时看这里.txt」复制。

1. 打开 dmg，把 **Cavil Loop** 拖进「应用程序」。
2. 双击打开。macOS 会提示无法验证开发者 / 无法打开——点「完成」或「取消」。
3. 任选一种放行方式：
   - **系统设置**：打开「系统设置 → 隐私与安全性」，往下翻到「已阻止使用 Cavil Loop」，点「仍要打开」，输入开机密码，再在弹窗里点「打开」。（macOS 14 及更早也可以在 Finder 里右键 App →「打开」→「打开」。）
   - **终端**：运行下面这行，然后正常双击打开：
     ```bash
     xattr -dr com.apple.quarantine "/Applications/Cavil Loop.app"
     ```
4. 之后就和普通 App 一样。**每装一个新版本**都要重新做一次第 3 步。

怎么验证过的：发版流程在 GitHub 的 Mac 机器上，对两个 dmg 都做了：直接启动通过冒烟测试；标上「从网络下载」后 Gatekeeper 确实拒绝；执行上面的终端命令后，用和双击相同的方式（`open`）能正常启动。「系统设置 → 仍要打开」这条路要人点按钮，CI 上没法点，没有自动验证。

### 登录

点「用 GitHub 登录」→ App 显示一个短码 → 点「打开 GitHub 授权页」→ 在浏览器里输入短码，点「Authorize」。登录方式默认是「OAuth 应用」，直接用；也可以选「GitHub App（预览）」，但这一版没有内置的 GitHub App，要填你自己建的 App 的 Client ID。两种的区别点选项旁的「两种有什么区别？」看。授权页上列出的权限：OAuth 应用是 `repo`（含代码与设置）、`read:org`、`project`；GitHub App 是那个 App 登记时勾选的权限（可以只给 Issues、Pull requests、Projects，不给代码），以授权页为准。所填 Client ID 和所选方式对不上时不让登录。令牌如果会过期（看应用的设置），App 会在到期前自动续期，你感觉不到。凭据存进 macOS 钥匙串（条目名「Cavil Loop (GitHub)」），下次启动不用再登录；在设置里「退出登录」会同时删掉它。GigleAI 组织如果开了第三方应用限制，第一次授权需要组织管理员批准。

### 提醒（`pending/human`）

- 「待处理」= 所有已加入来源里带 `pending/human` 的条目，**开着、已关闭、已合并都算**。标签名就是设置里「交回 agent」那一节的「等人处理的标签」，两处共用一个设置，要和 daemon 配置里的保持一致（不区分大小写）。
- 某条目上一轮还不是待处理、这一轮是了，就弹一次系统通知；点通知在浏览器里打开那条。标签摘掉再挂上，会再通知一次。同一条目在几个来源里出现，只通知一次、只算一个。
- App 启动后第一次同步成功、以及新加一个来源后它第一次同步成功时，已经带标签的条目不逐条弹，只弹一条汇总，比如「11 条待处理 · 其中 8 条已关闭 / 已合并」。想让数字变小，去 GitHub 上把旧条目的标签摘掉。
- 某个来源这一轮没读全（断网、凭据失效、分页读到一半失败），它这一轮不参与比较：不会冒出「新增」，也不会把条目当成「已移除」。恢复后真正的变化照常通知。
- Dock 角标 = 汇总里的数 = 设置页「现在待处理」的数。启动后第一次同步成功之前，角标不显示。
- 关掉窗口 App 仍在后台运行（Dock 图标保留），点 Dock 图标回到窗口；完全退出用菜单「退出」或 ⌘Q。设置里可以勾「开机自动启动」，开机启动时不弹窗口。
- 第一次弹通知时，macOS 可能先问是否允许 Cavil Loop 发通知，点「允许」。macOS 拒绝了通知（没允许、或在系统设置里关掉了）时，看板顶部和设置页会显示一条黄色提示，写明去「系统设置 → 通知 → Cavil Loop」打开「允许通知」；角标不受影响。下一条通知成功弹出后，提示自动消失。
- 仓库来源只读开着的、加上最近 14 天有更新的条目：给很早关闭的条目打标签会刷新它的更新时间，所以照样会提醒；但一条已关闭、14 天没动过的待处理条目会从仓库来源里掉出去（看板来源不受影响，看板里的条目全读）。
