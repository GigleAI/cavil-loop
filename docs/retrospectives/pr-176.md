## 最佳实践（有适用条件）
1. 当界面文案原本兼作测试断言时，删文案前先把断言迁到真正起保护作用的行为上，例如请求参数。验证方法：恢复文案的负对照变红，请求断言仍在。
2. 偏好类默认值，如果依赖外部读取的允许列表，就在展示时计算，不要靠 effect 写回状态。只有用户亲手改变才写入记录。验证方法：临时关闭某个选项再恢复，原记录仍有效。
3. 本地偏好读取时逐项校验，并放在独立键里，避免被视图设置导入覆盖。这是一种可行做法，不是唯一架构。
