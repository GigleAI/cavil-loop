## 最佳实践（有适用条件）
- 适用条件：新增 UI 入口，且某个已有入口已承担同一业务规则。做法：让新入口调用同一函数，再用测试覆盖「一边的副作用，另一边也有」。验证：真实窗口里点击后读界面状态。
- 适用条件：实现中发现与设计稿冲突（如布局测试超出边界）。做法：保留测试约束，取最小偏差，并在 PR 正文单列披露。验证：偏差处另有断言（本 PR：360 宽时按钮无文字、读屏名仍在）。
- 这不是唯一架构：「复用同一函数」是对本次需求合适，若两入口语义本就不同则不适用。
