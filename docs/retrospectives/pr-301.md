## 最佳实践（有适用条件）
- 当同一业务规则要在两个视图（看板 / 表格）生效时，把规则抽成共享纯函数，并让两侧执行同一段处理代码；验证方法：用同一份录制数据逐行、逐目标对拍两侧结果（含拒绝原因与确认选项）。适用于规则容易漂移的场景；规则本就不同则不必强行共用。
- 方案阶段就披露已知限制（空组不可拖、文字不可选）并在 PR 正文再次声明，使复审和合并没有信息缺口。
- 界面行为测试走真实窗口与真实后台，同时配成功写入断言和零写入断言，避免只靠「没发生」判定通过。
- 当不能在本机跑 CI 使用的引擎时（WebKit），明确写出实际引擎与未验证范围。
