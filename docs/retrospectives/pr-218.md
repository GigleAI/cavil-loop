## 最佳实践(有适用条件)
- 同一裁法在 shell 和 Python 各有一份实现时,用同一批夹具逐字节对拍(本 PR 为 19 个)。验证方法:对拍加各调用点的负对照开关。这与 L3 相吻合,是做对的案例,但不是新错误。
- 缩短“派工内容”时,把“展示内容”与“长度校验口径”拆开,避免缩短后放宽上限。适用于存在上限校验且依赖同一文本函数的场景。验证:新增“整份超限、裁后不超限仍被拒”的单测(PR 称新增 3 个单测,复审只确认了拼装与复盘测试的整体通过)。
- 测试预期从原始经验文件解析得到,而不是照输出抄写;对删除项的零出现断言,配套正向断言,防止空过。适用于断言“某内容不应出现”的测试。
