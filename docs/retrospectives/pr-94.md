## 最佳实践（有适用条件）
- 适用于：修改输出格式并有多个调用入口时。
  - 做法：用真实子进程断言输出文字，并对每条新检查配改坏后变红的负对照。
  - 验证：把新测试套到旧版本，核对失败数并拆分成因。
- 适用于：测试用管道把检查送进计数器时。
  - 做法：注意管道右侧在子 shell 里。可对比「打印的通过数」与「实际 ✅ 行数」。
  - 验证：故意制造一条失败，确认整套退出码非零。
- 适用于：需求一部分要在别的仓库实现时。
  - 做法：交付说明里分开写「已落地」与「待别处落地」。
