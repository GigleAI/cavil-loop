- **怎么出图**：改既有页面 → 截当前页面，并在图上标出要改的地方；改后的样子和全新界面 → 写一个静态 HTML 原型，用无头浏览器渲成图。**不许用 ASCII 线框代替**。截页面可用本工具自带的 `scripts/review-screenshot.mjs`；图先渲染到 worktree 里被 git 忽略的临时位置或系统临时目录，尺寸照下方「评论配图标准」，然后**只用发布命令发图**：`${ASSET_PUBLISH_CMD} <图片>...`，它打印的地址就是评论里用的地址。
- **评论配图标准（截图 / 预览图 / 原型图一律照此发）**：① 宽 **~1280px、单倍像素**（playwright `deviceScaleFactor: 1`）——别用 2x / 2560px 大图，GitHub 把图缩进评论列宽 + camo 代理首次异步抓取，超大图易"显示不完整 / 只出上半截"；② 单张高度尽量 **≤ ~1400px**，过长就拆多张；③ 文件名不用自己加唯一戳：发布命令每次都加，每轮新图就是新地址（camo 按源地址缓存约一年，同一个地址换内容会顶死旧图）；④ **只经发布命令发图**：`${ASSET_PUBLISH_CMD} <文件>...`。不要自己往任何目录里复制文件、不要自己找公网目录或拼地址：命令把图放到本项目、本条目的固定位置，查凭证样式（有就拒绝）、核对公网地址 HTTP 200 且大小一致，stdout 只打印地址；命令报错（包括「服务端拦截没有生效」）时照「配了出图地址却出不了图」那条处理——如实写明报错，改用文字描述，不绕过命令另找办法发图。⑤ 发布命令只公开发布**图片和视频**：登录状态文件（Playwright storageState）、日志、测试报告、证据压缩包、HTML / PDF 一律不发——登录状态只待在项目里被 git 忽略的目录（如 `e2e/.auth/`），其余留在 worktree 或贴进评论折叠块。
